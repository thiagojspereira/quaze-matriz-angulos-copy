# Matriz de ângulos para anúncios

Skill para criar e revisar ângulos, copys e anúncios a partir de desejos e estágios de consciência. Ela ajuda a distinguir ângulos de variações criativas e a escolher abordagens adequadas à oferta e ao público.

As instruções estão em [SKILL.md](SKILL.md). A skill foi criada para o contexto da QUAZE e menciona Thiago; adapte-a se necessário ao seu uso.
